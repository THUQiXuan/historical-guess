# 人物库：范围、来源与校勘说明

本版是供猜人物游戏使用的 **269 人精选库**，不是公元 184–316 年全部在世人物名录，也不是《三国志》完整人名索引。2026-09-17 整理、查阅。共含女性 23 人；237 人具有《三国志》具体卷内原文证据；有西晋阵营标签的 48 人。阵营可多选，因此各阵营计数不能相加当作总人数。

## 年代范围

采用公元 **184–316 年，首尾均包含**。判断的是生存时间是否与该区间相交，而不是必须出生、去世或成名于区间内。示例：张角死于 184 年，纳入；管宁生于 158 年、卒于 241 年，纳入；谢尚生于 308 年，主要事迹在东晋，仍纳入；晋愍帝司马邺活到 318 年，也纳入。184 年以前已经去世，或 316 年之后才出生的人不纳入。

`birth_year`、`death_year` 为公元整数年；未知、分歧较大或本次没有稳妥确定的年值置 `null`。这些年值是古代纪年换算及传载年龄推算的常用年表值，并非精确到生日的现代登记数据。虚岁推算、公历与古代岁首差异可能造成一年左右差别。孙坚卒年、凌统卒年、嵇康卒年等本版留空，避免把争议说法伪装成确定值。

`active_year` 是用于验证生存区间交集的参考年，表示当年在世，**不表示人物已经从政或成名**，也不表示摘要里的全部事件都发生在当年。对于出生于区间内的儿童，生存本身已满足入库规则。游戏问精确年代时应遵循明确题意，并以原典和题库纪年基准为依据。

## 《三国志》筛选口径

本版筛选涵盖陈寿正文及裴松之注，包含注中引用书籍的作者姓名；不是仅限本传主人公。每个 `sanguozhi: true` 条目都带 `sanguozhi_evidence`，包含卷次、可访问原文 URL 和真正的古籍正文片段。姓名有时以帝王讳、字、后妃称谓出现，例如曹丕的“文皇帝讳丕，字子桓”。相关称谓在 `aliases` 中辅助识别。

`sanguozhi: false` 表示**本次尚未建立《三国志》原文命中证据**，所以不进入这个严格的已核实子集；它不构成“整部书中绝对没有此人”的学术断言。不能直接把 false 当作回答“此人是否见于《三国志》”的否定史实，仍应查原文。若希望缩到“只含陈寿正文”“只限有独立本传”之类范围，应由 agent 按额外要求重新核定候选。

原文引用保留传文的异体字和部分断句；不会把网页目录、维基百科导览、搜索摘要、模型自行生成的句子当成证据。来源阅读片段曾在临时目录保存并逐条匹配；这些浏览缓存不在仓库中。原文可能含裴注转引的不同史料观点，**出现某段记载不代表它的全部内容已被认定为无争议史实**。

## 历史与小说

人物、事实摘要以《三国志》《后汉书》《晋书》为主。默认不是《三国演义》题库：不收貂蝉、周仓等仅据文学形象建立的条目，不把“桃园结义”“温酒斩华雄”等小说情节当作人物事实。女性若没有可靠本名，使用史籍称谓，例如甄夫人、步夫人、吴皇后；不擅自补成“甄宓”“步练师”。张飞“益德”与通俗写法“翼德”等可作猜名时的别名容错，别名不等于史实姓名的独立证据。

`factions` 是游戏用政治归属标签，可包含先后效力的多个集团。曹魏、蜀汉、孙吴标签也包含曹操、刘备、孙氏建国以前的集团成员；例如死于 219 年的关羽仍归入蜀汉集团。它不表示该人物一定活到正式建国，也不意味着每个标签都是本人正式任官过的国号。东晋及晋末其他政权暂归“其他”，具体身份以摘要与原文为准。角色标签是便于筛选的现代概括。

## 可复核的来源

- 陈寿撰、裴松之注：[《三国志》](https://zh.wikisource.org/zh-hans/三國志)，主要利用魏书、蜀书、吴书各人物本传及裴注。每条记录都有具体卷次链接。
- 范晔撰、李贤等注：[《后汉书》](https://zh.wikisource.org/zh-hans/後漢書)，用于汉灵帝、汉献帝、黄巾起义、皇甫嵩、朱儁、卢植、何进、蔡琰等人物。注意维基文库卷 8、卷 9 的 URL 不加前导零。
- 房玄龄等撰：[《晋书》](https://zh.wikisource.org/zh-hans/晉書)，用于司马氏、西晋女性、八王之乱、文学家、晋末及后来活跃于东晋的人物。比如西晋后妃在 [卷 31](https://zh.wikisource.org/zh-hans/晉書/卷031)，不是东晋后妃为主的卷 32。

`characters.json` 的 `sources` 指向本次核查过的 98 个具体古籍网页。`facts` 是简短的编辑摘要，不是对整个人生的完备知识表示；未列在 facts 中，不等于历史上不存在这项事实。每局 agent 必须在固定人物的前提下结合可靠史料判断，不能只用关键字匹配回答。

## 维护与校验

JSON 是人工校订的权威题库文件，`scripts/build_corpus.py` 是验证器，名称沿用构建脚本约定；**它不会联网爬取或自动重新生成历史事实**。以后增补人物时，应先查具体卷原文，再更新 JSON，并运行：

```sh
python scripts/build_corpus.py
```

校验覆盖字段、重复 ID/姓名、性别/阵营取值、在世参考年与生卒年关系、女性和年代两端的覆盖、true 标记必须带原文证据、来源 URL 一致性，并拒绝引文中夹带浏览器行号、工具引用标记、网页导览或域名。可选 `--check-source-cache DIR` 会逐条核对引文是否存在于浏览器读取的卷文片段中（此项依赖维护者自己保留的临时阅读缓存）。这些结构校验不代替历史考据。

古籍作者分别为陈寿／裴松之、范晔／李贤等、房玄龄等；古代原文本身已进入公有领域。所查网络转录版来自维基文库及其贡献者，排版、校订、标点等编辑部分应按相应页面许可处理。网页可通过“查看历史”追溯编辑者。
